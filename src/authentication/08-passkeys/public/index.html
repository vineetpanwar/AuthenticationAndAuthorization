Passkeys (WebAuthn/FIDO2) Demo

Passwordless authentication using public-key cryptography

Registration: Browser ---[1. Request Options]---> Server Browser <--[2. Challenge + Config]-- Server Browser ---[3. Create Credential]--> Authenticator (Touch ID, etc.) Browser ---[4. Send Attestation]---> Server Browser <--[5. Verified! Stored.]--- Server Authentication: Browser ---[1. Request Options]---> Server Browser <--[2. Challenge + IDs]---- Server Browser ---[3. Sign Challenge]-----> Authenticator Browser ---[4. Send Assertion]-----> Server Browser <--[5. Verified! Welcome.]- Server
How it works: Passkeys use public-key cryptography instead of passwords. During registration, your device creates a unique key pair. The private key stays on your device (secured by biometrics/PIN), while the public key is sent to the server. During login, the server sends a challenge, your device signs it with the private key, and the server verifies the signature with the public key. No secrets are ever transmitted.

Register a Passkey

Create a new account and register a passkey for it.

  • 1Server generates a challenge and options
  • 2Browser triggers authenticator (biometric/PIN prompt)
  • 3Authenticator creates a key pair; private key stays on device
  • 4Public key + attestation sent to server for storage

Login with Passkey

Authenticate using a previously registered passkey.

  • 1Server generates a challenge and allowed credentials
  • 2Browser triggers authenticator (biometric/PIN prompt)
  • 3Authenticator signs the challenge with the private key
  • 4Server verifies signature using the stored public key
